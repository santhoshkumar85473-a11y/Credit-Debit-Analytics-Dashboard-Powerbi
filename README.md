 Power BI Banking Analytics Projects

 📌 Overview
This repository contains two banking analytics projects developed using Microsoft Power BI. These projects demonstrate data visualization, financial KPI analysis, dashboard development, and the ability to convert raw data into meaningful business insights.
 📊 Projects

1. Credit-Debit Analytics Dashboard
File: `credit debit.pbix.zip`

Objective:Analyze credit and debit transactions to understand transaction patterns and banking activity.

Key areas of analysis:**
- Credit and debit transaction analysis
- Transaction amount comparisons
- Financial KPI monitoring
- Transaction trends and patterns
- Identification of potentially unusual transactions, where supported by the data

**Tools:** Microsoft Power BI, Data Visualization, Data Analysis

2. Banking Analytics Dashboard
**File:** `Bank analytics.pbix.zip`

**Objective:** Analyze banking loan data to understand loan distribution, financial performance, and loan repayment risk.

Key areas of analysis:
- Loan distribution and analysis
- Financial KPI calculations
- Loan default and delinquency patterns
- Banking portfolio insights
- Data-driven financial analysis

Tools: Microsoft Power BI, SQL (where applicable), Data Analysis, Data Visualization

🛠️ Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- SQL (for applicable data preparation and analysis)
- Data Cleaning and Transformation
- KPI Development
- Interactive Dashboard Design

Tools listed above should be retained only if they were actually used in the projects.

 🎯 Skills Demonstrated
- Data cleaning and preparation
- Financial and banking data analysis
- KPI analysis
- Dashboard design and visualization
- Identifying trends and patterns
- Presenting insights for business decision-making

🚀 How to Use
1. Download the ZIP file for the project you want to explore.
2. Extract the ZIP file.
3. Open the `.pbix` file using Microsoft Power BI Desktop.
4. Explore the dashboard and interact with the available filters and visualizations.
